# Rock Paper Scissors Game (JavaScript)

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript.  
The game allows the user to play against the computer with real-time score updates and reset functionality.

---

## Features

- Interactive Rock, Paper, Scissors gameplay
- Random computer choice generation
- Score tracking for user and computer
- Result messages for win, loss, or draw
- Reset game functionality
- Clean and simple user interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## How It Works

1. User selects Rock, Paper, or Scissors
2. Computer randomly selects an option
3. Game logic determines the winner
4. Scores are updated instantly
5. User can reset the game at any time

---

## Purpose

This project was created to practice:
- JavaScript game logic
- DOM manipulation
- Event handling
- UI interaction
